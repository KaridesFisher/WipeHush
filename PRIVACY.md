# Privacy

WipeHush does not collect or transmit personal data. It has no analytics SDK, crash-reporting service, ads, account system, network client, updater, or third-party dependencies.

Accessibility permission is used to create an input event tap during a cleaning session. Selected input events are discarded. Only Escape press/release state and session timing are retained in memory. Typed characters are not stored, recorded, or transmitted.

The app does not save preferences or session history. macOS may maintain its own permission records, application state, and diagnostics outside the app's control. WipeHush opens System Settings only when you click the permission button.

GitHub's website, release downloads, and README badge services operate under their own policies. They are not contacted by the WipeHush application.
