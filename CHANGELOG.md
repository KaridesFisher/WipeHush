# Changelog

## 1.2.0

- First public open-source release under the MIT License.
- English-only interface, menus, permission help, errors, and documentation.
- Redesigned dark AppKit interface with live Accessibility status.
- Session duration choices: 30 seconds, 1 minute, or 2 minutes.
- Visible hold-to-unlock progress and a monotonic automatic timeout.
- Escape handling based on intercepted press/release events, including autorepeat protection.
- Session cleanup on sleep, user-session changes, and display reconfiguration.
- Universal Apple Silicon and Intel builds, regression tests, and release automation.

## Earlier personal builds

Versions 1.0 and 1.1 were personal prototypes. They are superseded by this release and are not distributed here.
